# Packages the Isaac AutoData interpreter needs beyond what its own conda_installer.sh provides.
#
# Install with `tools/launch_autodata.sh setup`, which also runs as a preflight check before every
# other command so a missing or wrong version is reported rather than surfacing as a crash deep in
# the simulation.
#
# Pink deliberately overrides what AutoData's pinned Isaac Lab distribution declares, so pip
# reports it as a conflict. DAQP matches that distribution's requirement.

# Isaac Lab's Pink IK passes warm-start arguments through qpsolvers that 0.7.2 rejects, and it
# raises rather than falling back, so the G1 cannot be stepped at all on the older version.
daqp==0.8.5
# Match the Pink version runtime.toml pins, so generated trajectories are solved by the same IK
# that recording and evaluation use. Verified behaviour-neutral on AutoData's own G1 example.
pin-pink==3.3.0
# Imported by this repository's env cfg, which AutoData builds when driving our task.
loguru==0.7.3
